# 5.12 Validation protocol — what each metric measures, and how it lies

Extracted from the SENNA Master Implementation Specification v3.0 (7 July 2026) — docs/spec/source/SENNA_Master_Spec_v3.pdf, Part 5. The PDF is the authority; report divergences, never patch them here.

Every metric ships with its definition, its target, and a written account of how it can be gamed or misread — plus the mitigation. This table is the honest core of Chapter 7 and directly answers your brief.

| Metric | Definition and measurement | Target | How it can be gamed / misread -> mitigation |
|---|---|---|---|
| M1 Paired position delta | Mean finishing-position delta vs the rule-based baseline over 500 paired seeds (identical event draws), bootstrap 95% CI | Mean at least +1.0 with CI excluding 0 | Weak rivals inflate it -> rivals fitted to data, evaluation uses the held-out rival band (E-06); also reported vs replayed-real strategies (M2) |
| M2 Counterfactual vs actual | The 10 v2 races, era-matched (F-24): agent strategy vs the team's actual strategy replayed in the same simulator, same seeds | Mean at least +1.0 (v2's +1.5 kept as stretch) | Sim optimism: the agent optimised the very simulator it is scored in, real teams optimised reality -> framed as "in-simulator counterfactual under stated assumptions", read alongside M8 sim-to-real error |
| M3 Oracle regret | Gap in finishing time/position to a full-information dynamic-programming strategist on the deterministic twin of each eval race | Report distribution; no hard target in run 1 | An easy oracle flatters the agent -> oracle definition published (search space: all pit-lap x compound plans x greedy energy); regret reported with the oracle's assumptions |
| M4 Energy utilisation | Deployed / E_dep on green laps; derate events per race | At least 0.90; derates under 5% of laps | Trivially maxed by always attacking -> only meaningful jointly with M1/M2; reported as a pair with derate rate |
| M5 SC/VSC decision quality | Against the ex-post afterstate optimum per neutralisation window: precision AND recall of "pit now" calls, VSC and SC separated (E-03) | Both at least 0.75 | Always-pit inflates recall -> precision reported jointly; window definition (denominator) published — this replaces v2's single gameable "78% exploitation" number, and the +2.5 reward that pre-paid it is gone (F-17) |
| M6 Pit window accuracy | Share of pits within 3 laps of the post-hoc optimal lap (afterstate search), kept from v2 with the optimum now defined | At least 0.72 (v2 kept) | Optimum depends on the search's information set -> information set stated (no future event knowledge) |
| M7 Strategy diversity | Entropy of (stop count x first-stop compound) across 1000 eval races, per circuit | Report (v2's 2.1 nats dropped as arbitrary) | Dithering fakes diversity -> sanity metric only, never a headline |
| M8 Sim-to-real | Section 5.4.1 suite on held-out 2026 rounds | KS under 0.15 per circuit; pit loss within 1.0 s | Calibrating on the test rounds -> split frozen now (E-14) |
| M9 Tyre failure rate | Thermal failures per 100 eval races | Under 2.0 (fixes v2's reversed "> 2.0") | Trivially zero by never stretching stints -> read jointly with M1 and stint-length distributions |
| M10 Regulatory legality | 100k-random-action property test + zero illegal actions in all eval logs | 100% by construction (A-01) | Nothing to game — that is the point of moving compliance out of the reward (F-16) |
| M11 Luck share (A-08) | Variance decomposition: fix the policy, vary event seeds vs vary decision noise; share of finishing-position variance attributable to event draws | Report — a novel analytics finding | Depends on event-model realism -> event rates validated per circuit first (5.4.1) |
