# 5.5 Gymnasium environment contract (F1RaceEnv)

Extracted from the SENNA Master Implementation Specification v3.0 (7 July 2026) — docs/spec/source/SENNA_Master_Spec_v3.pdf, Part 5. The PDF is the authority; report divergences, never patch them here.

One environment class, parameterised by era (2024 or 2026 constants file) and circuit config. Decision frequency: one step per lap (kept from v2 — see Part 4.1). Episode length: the race distance, 44–70 steps.

## 5.5.1 Observation space — Box(low=-1, high=1, shape=(32,), float32)

Every dimension named, bounded and justified. VecNormalize runs on top during training; the raw encodings below are already scale-bounded so the served model degrades gracefully if statistics drift.

| # | Name | Encoding / range | Why the strategist needs it |
|---|---|---|---|
| 1 | lap_progress | lap / total_laps, [0,1] | Race phase changes the value of every action; laps_remaining is its complement so one scalar suffices |
| 2 | position_norm | (position - 1) / 21, [0,1] | Objective context; 22-car grid |
| 3 | grid_delta | (grid - position) / 21, [-1,1] | Whether the race is being won or lost vs start — cheap trend signal |
| 4–8 | compound one-hot | S / M / H / Inter / Wet | Degradation anchor (kept from v2) |
| 9 | tyre_age_norm | age / 40, clipped [0,1] | Primary degradation driver |
| 10 | grip_est | model grip estimate, [0,1] | The simulator's own tyre state — the analogue of an engineer's deg model |
| 11 | tyre_temp_state | {cold 0, optimal 0.5, hot 1} | Cliff-risk signal |
| 12 | pit_count_norm | stops / 3, clipped [0,1] | Strategy shape so far |
| 13 | second_compound_used | {0,1} | The mandatory two-compound rule (F-20) — without this the rule is invisible to the policy |
| 14 | fuel_frac | mass / initial, [0,1] | Weight effect and burn planning |
| 15 | soc_frac | SOC / 4 MJ, [0,1] | The central 2026 resource |
| 16 | last_lap_harvest_frac | harvested / H_max, [0,1] | Energy-economy feedback: is banking working |

## 5.5.2 Action space — MultiDiscrete([6, 4]) with masking

| Head | Values | Mask rules (each rule logged with a reason code) |
|---|---|---|
| A: pit decision | 0 stay out · 1 pit Soft · 2 pit Medium · 3 pit Hard · 4 pit Intermediate · 5 pit Wet | Pit choices masked while pit lane closed; slicks masked when wetness above the slick threshold; Inter masked outside damp band; Wet masked unless wet; stay-out masked on the last feasible pit lap of a dry race if second_compound_used == 0 (F-20) |
| B: energy / pace mode | 0 conserve (lift-and-coast harvest, pays pace) · 1 balanced · 2 attack (max deploy toward E_dep) · 3 defend (deployment weighted to the car behind) | attack masked when SOC below 0.5 MJ (nothing to deploy — masking beats letting the agent learn a no-op); defend meaningful only with a car within 2.0 s behind but never illegal, so unmasked |

Legality that is continuous rather than discrete (energy conservation, SOC bounds, harvest caps) is enforced inside the dynamics by clipping and derating — the agent can request, physics disposes. Together with the masks this is what makes "100% compliant by construction" true (F-16), and the 100k-random-action property test proves it.

## 5.5.3 Transition dynamics (per lap, per car — all 22 cars run the same model)

```
lap_time = t0(circuit, era)                     # fitted per circuit per era
         + k_m * fuel_mass                      # k_m fitted jointly (E-10)
         + deg(compound, age, track_temp)       # grip model, T5
         + mode_pace(mode)                      # conserve +c_lc; attack -c_atk (energy-bounded)
         + traffic(gap_ahead, era)              # dirty air under 2.0 s, era-scaled
         + status_mult(track_status)            # VSC / SC multipliers, fitted
         + wet_penalty(wetness, compound)       # crossover model, E-08
         + eps,  eps ~ N(0, sigma_driver)       # per-car pace noise, fitted

harvest = min(H_max(circuit),
              H_brake(circuit) + [mode==conserve] * H_lc + H_clip(circuit))
deploy  = min(D_request(mode), E_dep(circuit), SOC + intra_lap_share * harvest)
derate_penalty = p_der * max(0, D_request(mode) - deploy)   # s per MJ shortfall
SOC'    = clip(SOC + harvest - deploy, 0, 4.0)

events: SC ~ hazard lambda_c per lap; VSC from per-car failure hazard;
        weather Markov per circuit; tyre-failure hazard beyond cliff age -> forced pit
        (+25 s, kept from v2); red flag -> positions per rules + free tyre choice (E-04)
ordering: cumulative race time; on-track passes gated by P(pass) (T7);
          pit lane is a FIFO with per-car service-time draws (E-05)
```

Every named constant above lives in physics_params.yaml with a comment stating its source: fitted (which notebook), sourced (which document, see Part 8), or stylised (explicitly labelled). That file is the anti-black-box artefact for the physics layer.

## 5.5.4 Reward — three terms, each with its coefficient argued

| Term | Formula | Coefficient and why exactly that value |
|---|---|---|
| Pace shaping | r_pace = w_p * (t_ref(c) - lap_time) / s_ref(c) | w_p = 0.02. s_ref is the per-circuit clean-lap standard deviation, making the term scale-free across circuits; over a 60-lap race its total magnitude is about 1.2 at most — an order below the terminal term, so it provides per-lap gradient without competing with the objective. Ablation 4 trains without it. |
| Position shaping (potential-based) | F = gamma * Phi(s') - Phi(s), with Phi(s) = -0.1 * position | Coefficient 0.1: a net one-place gain contributes +0.1 in total because the sum telescopes — its job is direction, not magnitude. Potential-based form (Ng, Harada, Russell 1999) provably leaves the optimal policy unchanged and pays exactly zero for the oscillation exploit that broke v2 (F-15). |
| Terminal points | R_T = points_2026(final position) / 2.5 (P1 = 10.0, P2 = 7.2, ... P10 = 0.4, else 0; DNF = 0) | Divisor 2.5 sets P1 = 10, about 3x the maximum cumulative shaping (~1.2 + ~2.1), so the terminal objective dominates — the dominance ratio is logged per run. Using the real points table makes the objective legible to any F1 person. DNF pays 0 rather than negative: retirement already forfeits everything; stacking an extra penalty double-counts risk (documented choice, optional ablation). |

Per-lap reward decomposition (all three terms separately) is written to the episode log for every evaluation race — the interpretability contract row for this component.

## 5.5.5 Termination, truncation and the info dict

- `terminated = True` at race distance, or on retirement (fuel/energy exhaustion, terminal car failure event). Tyre failure is NOT termination: forced pit + 25 s (kept from v2).
- `truncated` is never used: the horizon is the race by definition.
- Red flag: not a termination — field neutralised, positions per regulations, free tyre choice granted (E-04), race resumes.
- `info` per step: position, gaps, per-term reward decomposition, energy triplet (harvest, deploy, SOC), mask bit-vector with reason codes, event flags. `info` at episode end: final position, points, pit laps and compounds, derate count, energy totals.
- `reset(seed=...)` fully seeds every stochastic stream (events, rivals, noise) — the SubprocVecEnv statelessness requirement from v2 Section 13.2 is kept verbatim.
