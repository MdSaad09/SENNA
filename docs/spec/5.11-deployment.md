# 5.11 Deployment — local compose for dev, Railway services for prod

Extracted from the SENNA Master Implementation Specification v3.0 (7 July 2026) — docs/spec/source/SENNA_Master_Spec_v3.pdf, Part 5. The PDF is the authority; report divergences, never patch them here.

## 5.11.1 Service graph

| Service | Local (docker compose) | Railway (one service each) | Notes |
|---|---|---|---|
| postgres | postgres:16-alpine + volume | Railway Postgres plugin | Alembic migrates on api start (kept from v2) |
| redis | redis:7-alpine | Railway Redis plugin | Queue + pub/sub + cache |
| api | uvicorn, port 8000 | Dockerfile.api | Health at /api/v1/health; CORS allowlist = frontend origin |
| worker | rq worker | Dockerfile.worker (same image as api) | Frozen model triplet baked into the image at /app/models; MODEL_VERSION env selects it (F-26; Railway filesystems are ephemeral, so no mounted ./models) |
| frontend | vite dev server | Static build (Railway static or nginx image) | Built with the public API URL (F-27) |

## 5.11.2 Environment variables (the F-27 fix lives here)

| Variable | Local dev | Production | Note |
|---|---|---|---|
| DATABASE_URL / REDIS_URL | compose service names | Railway plugin references | Server-side only — containers can resolve service names |
| VITE_API_BASE | /api (vite proxy to localhost:8000) | https://<api>.up.railway.app/api | Baked into the JS bundle at build time; must be browser-reachable — never a Docker hostname (F-27) |
| VITE_WS_BASE | ws://localhost:8000/ws | wss://<api>.up.railway.app/ws | wss in production or browsers block mixed content |
| MODEL_VERSION | dev-latest | e.g. v3.0-stageC-seed1 | Part of every cache key (E-15) and every API response |
| WANDB_API_KEY | set locally for training only | ABSENT | Training never runs in serving (F-26); v2 had it in the api container |

Reproducibility pack (A-09): make ingest / make fit / make train / make eval / make report; a seeds.yaml manifest; config hashes in every result row; a frozen data snapshot archived once ingestion completes.
