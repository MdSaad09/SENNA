# 5.13 Recruiter demo — the first 90 seconds, engineered

Extracted from the SENNA Master Implementation Specification v3.0 (7 July 2026) — docs/spec/source/SENNA_Master_Spec_v3.pdf, Part 5. The PDF is the authority; report divergences, never patch them here.

A hiring manager decides in the first minute whether this is a template project or an engineer's project. The opening sequence is therefore specified as tightly as the API.

| Time | What they see | What it proves |
|---|---|---|
| 0-15 s | URL opens directly into a Live Simulation already mid-race (deep link with seed + circuit in the query string): 22 cars moving, agent car highlighted, SOC bar draining and refilling | Deployed, fast, real system — not a video; energy dynamics visible immediately |
| 15-45 s | Lap ~18: the decision card slides in — PIT probability, top-5 SHAP drivers, the counterfactual flip line, and the fidelity badge (e.g. "surrogate agreement 93%") | Explainability with stated honesty — the badge is what separates engineering from marketing |
| 45-75 s | One click to the Counterfactual view: split screen, agent vs the real 2024 strategy, divergence flash at the pit lap, position-delta chart ticking upward | Quantified value against reality, era-matched, with the assumptions printed on screen |
| 75-90 s | One click to the Energy view: SOC trajectory against the per-circuit harvest cap; hover a lap where the model banked energy before an attack | Correct 2026 physics — the exact place a motorsport engineer probes first, and where v2 would have failed |

The v2 ten-minute script (Section 14.2) is kept as the long-form tour with four edits: the ERS Landscape beats become the Energy view beats; "Verstappen's car" becomes the three-letter data code; the W&B beat adds the masking-vs-penalty ablation; the closing GitHub beat shows the reproducibility Makefile.
