# 6.3 The Minimum Defensible Product and the cut order

Extracted from the SENNA Master Implementation Specification v3.0 (7 July 2026) — docs/spec/source/SENNA_Master_Spec_v3.pdf, Part 6. The PDF is the authority; report divergences, never patch them here. (Extracted in F15 so the freeze's "nothing below the line was cut" check no longer needs the PDF open.)

MDP (end of Phase 4): corrected-physics environment + masked PPO agent + M1/M5/M8/M9/M10 with confidence intervals + decision cards rendered in a notebook. That alone is a passing MSc dissertation with genuine novelty (corrected 2026 energy model, masking architecture, sim-to-real validation). Everything after is distinction polish and recruiter material.

If you fall behind, cut in this order — and never cut below the line:

1. Views 3 and 4 become 2D Recharts panels (the data pipeline behind them is unchanged).
2. View 5 live streaming becomes playback of a precomputed run (the WS plumbing already supports this via E-16).
3. Ablations 3 and 4 drop to 1 seed each.
4. View 6 split viewport becomes a single canvas with an overlay position-delta chart.

**Never cut**: action masking, the cleaning contract, the calibration/validation split, the metric suite with its gaming notes, decision cards. These are the dissertation.
